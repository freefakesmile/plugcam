Plugcam decodes the phone's video with FFmpeg on the graphics chip and takes far less of the processor, and it can stream only while an app uses the camera. The first release of this fork ([freefakesmile/plugcam](https://github.com/freefakesmile/plugcam)).

## New

- **FFmpeg instead of Windows' decoder.** The video is decoded by FFmpeg 9.1 on the graphics chip through Direct3D 12 (`plugcam_dec.dll`, 1 MB), and a crop is done there too. On an i7-13700K with an RTX 3080 Ti, streaming 1080p30 with the window in the tray takes 118 ms of processor time a second instead of 458 (0.7% of the CPU instead of 2.9%), about 80 instead of 360–430 with a crop. The picture is the same. Where Direct3D 12 video decoding is not available, Windows' decoder takes over as before.
- **Stream only while an app uses the camera** (*Settings → Startup*). The phone's camera turns on when Zoom, Meet or another app opens "Plugcam Camera" (the picture arrives a few seconds later) and off as soon as the app lets go. In between, Plugcam takes almost nothing, so it can stay in the tray all day.
- **Crop the picture** by drawing a frame on the preview: the crop button on the preview.
- **Hide the preview** with the button next to it, while the camera keeps working; the window then costs no processor time for it.

## Fixed

- **Quitting with the camera on hung the app.** The tray's *Quit*, or closing the window with "close to tray" off, froze it and the process never exited.
- The labels over the preview were blurred again on every frame, which the graphics chip and the window paid for; they are plain now.

## Install

- **This build does not update itself:** new versions of this fork are published here. *Settings → Updates* has a link to this page.
- **Installer:** download `Plugcam_0.3.0_x64-setup.exe` below and run it. It replaces an installed Plugcam and keeps its settings.
- **Portable:** download `Plugcam_0.3.0_x64-portable.zip`, extract it anywhere and run `Plugcam.exe`.

The files are not code-signed, so SmartScreen may warn you: *More info → Run anyway*. The `.sha256` files next to them have the checksums.

## По-русски

Plugcam декодирует видео с телефона через FFmpeg на графическом чипе и тратит намного меньше процессора, а ещё умеет транслировать, только когда камеру использует приложение. Первый релиз этого форка ([freefakesmile/plugcam](https://github.com/freefakesmile/plugcam)).

- **FFmpeg вместо декодера Windows.** Видео декодирует FFmpeg 9.1 на графическом чипе через Direct3D 12 (`plugcam_dec.dll`, 1 МБ), там же выполняется обрезка. На i7-13700K с RTX 3080 Ti трансляция 1080p30 с окном в трее занимает 118 мс процессорного времени в секунду вместо 458 (0,7% процессора вместо 2,9%), с обрезкой — около 80 вместо 360–430. Картинка та же. Где декодирование через Direct3D 12 недоступно, работает декодер Windows, как раньше.
- **Транслировать, только когда камеру использует приложение** («Настройки → Запуск»). Камера телефона включается, когда Zoom, Meet или другое приложение открывает «Plugcam Camera» (картинка появляется через несколько секунд), и выключается, как только приложение её отпускает. Всё остальное время Plugcam почти ничего не тратит, так что его можно весь день держать в трее.
- **Обрезка картинки** рамкой прямо на превью — кнопка обрезки на превью.
- **Скрыть превью** кнопкой рядом с ней, камера при этом продолжает работать; окно тогда не тратит на превью процессор.
- **Исправлено:** выход с включённой камерой подвешивал приложение.

Эта сборка не обновляется сама: новые версии форка выходят здесь, ссылка есть в «Настройки → Обновления».
